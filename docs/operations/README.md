# Operations

Use [configuration and setup](../setup.md), [private scripts](../scripts.md), and [publication instructions](../development.md). Read availability from `release/manifest.yaml`; staged artifacts are not installable releases.

Both publication workflows keep existing protections. After first publication, a package administrator manually changes GHCR visibility to Public. The ordinary `verify-public` job verifies anonymous version/digest pulls, architecture and OCI labels. After correcting visibility, use **Re-run failed jobs**, not **Re-run all jobs**. Publication does not change client pins or enable voice/TURN.

The client supplies approved browser URLs/roles and per-bot machine permissions, Base auth/bridge SecretStores, bridge managed registrations, gateway callers, TLS approval and narrow network egress. Keycloak is required even for explicitly anonymous apps. Script-free bots need no object store; S3-loaded apps require the bucket and reader/publisher users before upload. Follow [app publishing](../scripts.md): the CLI edits only the Git working tree, then the operator reviews, commits and pushes for Flux reconciliation. Retain storage/users and never expose publisher credentials to bots.

Voice admission stays disabled until compatible speech endpoints and inference are accepted. TURN remains optional; separately verify browser TLS 443 through the existing edge SNI route to TCP 30549, the selected node, certificate and private Pod-to-Pod UDP relay path. No public UDP forwarding or external relay address is needed. Include `pipecat` in Reloader's watch and RBAC namespace lists. These settings do not prove live media readiness. Replacing a bot ends only that app's process-local calls/history; disabling it retains identity and credential ownership. Use a short maintenance window for approved rollout changes.
